Cách Hệ Thống Hoạt Động

Pipeline end-to-end từ ảnh đến ngôn ngữ tự nhiên

01
🖼️

Nhập Ảnh

Người dùng tải ảnh lên hệ thống qua giao diện web thân thiện. Hỗ trợ JPG, PNG, WEBP.

→
02
🔍

Trích Xuất Feature

InceptionV3 (pretrained ImageNet) trích xuất vector đặc trưng 2048 chiều từ ảnh.

→
03
🧠

LSTM + GloVe

Mô hình LSTM kết hợp GloVe 200d decodes vector thành chuỗi từ tiếng Anh.

→
04
🔦

Beam Search

Thuật toán Beam Search tìm kiếm các chuỗi có xác suất cao nhất để tạo ra captions đa dạng.

→
05
💬

5 Captions

Hệ thống trả về 5 câu mô tả đa dạng, phong phú về nội dung ngữ cảnh ảnh.

Kiến Trúc Model

  • Encoder InceptionV3 – CNN pre-trained trên ImageNet 1.4M ảnh
  • Embedding GloVe 200d – Word vectors từ 6 tỷ tokens
  • Decoder LSTM 256 units – Mạng hồi quy sinh từng từ
  • Decode Beam Search k=3,5 – Tìm chuỗi tối ưu
  • Metric BLEU-1: 0.45 – Đánh giá trên Flickr8k test set

📖 Hướng Dẫn

Cách Sử Dụng Hệ Thống

1

Chọn hoặc Kéo Ảnh

Nhấn vào vùng tải ảnh hoặc kéo thả tệp ảnh từ máy tính. Hỗ trợ JPG, PNG, WEBP tối đa 10MB.

2

Xem Trước Ảnh

Ảnh sẽ hiển thị ngay lập tức. Nếu muốn đổi, nhấn nút "Đổi ảnh".

3

Nhấn "Sinh Caption"

AI sẽ phân tích ảnh trong vài giây và tạo ra 5 câu mô tả bằng tiếng Anh.

4

Sao Chép Kết Quả

Nhấn icon 📋 bên cạnh từng caption để copy, hoặc "Sao chép tất cả" để copy cùng lúc.

💡 Mẹo để có kết quả tốt nhất

  • ✅ Sử dụng ảnh rõ nét, ánh sáng tốt
  • ✅ Ảnh có chủ thể rõ ràng (người, vật, cảnh vật)
  • ✅ Tránh ảnh quá tối hoặc bị mờ
  • ✅ Model được huấn luyện trên ảnh ngoài trời và chân dung
  • ⚠️ Captions bằng tiếng Anh (theo dataset Flickr8k)
